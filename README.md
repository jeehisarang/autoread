# 홀덤 게임 텍스트 기록 프로그램

시각장애인 사용자가 홀덤 게임을 복기하며 공부할 수 있도록, 지정한 게임 창에서
**플레이어들의 행동(Fold/Call/Raise/Bet/Check/All-in)만** 포지션(UTG/HJ/CO/BTN
/SB/BB)과 스트리트별로 정리해서 텍스트로 기록하고, 엑셀(.xlsx) 파일에 계속
누적 저장하는 프로그램입니다. **내 자리(화면 하단 중앙)의 행동만 색으로 구분**해서
한눈에 알아볼 수 있습니다.

## 기록 형식

```
[1게임 시작]

[프리플랍]
UTG ] Fold
HJ  ] Raise 1500
CO  ] Call
BTN ] Fold
SB  ] Fold
BB  ] Call

[플랍]
SB  ] Check
BTN ] Bet 2000
BB  ] Fold

[1게임 결과] BTN 승

[2게임 시작]
...
```

- 내 자리의 행동만 화면에서 초록색으로 표시됩니다 (엑셀에도 초록색 글씨로 표시).
- 텍스트 형태(`포지션 ] 행동 [금액]`)는 나와 다른 사람이 완전히 동일하며, "나"라는
  글자는 쓰지 않습니다 — 오직 색으로만 구분합니다.

## 동작 원리

1. 사용자가 화면에 떠 있는 창 목록 중에서 게임 창을 직접 선택합니다.
2. 기록이 시작되면, 일정 주기(기본 0.8초)로 창 전체(또는 선택 영역)를 캡처하고
   Windows 내장 OCR로 화면의 모든 텍스트를 읽습니다.
3. Fold/Call/Raise/Bet/Check/All-in 같은 **행동 키워드가 있는 텍스트만** 내용
   기준으로 걸러냅니다. 골드, UI 버튼, 채팅, 로비 배너 등은 기록하지 않습니다.
4. 화면에 항상 떠 있는 닉네임들의 위치를 계속 추적해서 6개의 좌석 위치를 파악하고,
   그중 화면 하단 중앙에 가장 가까운 좌석을 "내 자리"로 확정합니다. (한 번 확정되면
   그 판이 끝날 때까지 유지됩니다.)
5. **딜러 버튼을 화면에서 직접 인식하지는 않습니다.** 대신 "버튼은 매 핸드 한 자리씩
   이동한다"는 표준 규칙을 이용해서, 게임 번호만으로 각 좌석의 포지션
   (UTG→HJ→CO→BTN→SB→BB)을 계산합니다. 6명이 계속 앉아 있는 상태를 가정하며,
   중간에 자리 이동/인원 변경이 있으면 실제 포지션과 달라질 수 있습니다.
6. "Flop/Turn/River" 전환 문구로 스트리트를, "New Game" 같은 문구로 새 게임 시작을
   인식해서 게임 번호와 스트리트를 관리합니다. "승리/획득" 같은 문구가 보이면
   `[N게임 결과] 포지션 승` 형태로 결과를 best-effort로 표시합니다 (항상 뜨지는
   않을 수 있습니다).

## 설치

1. Python 3.11 이상 (Windows) 필요
2. 아래 명령으로 패키지를 설치합니다.

   ```
   pip install -r requirements.txt
   ```

3. **한국어 OCR 언어 팩 확인**: 설정 > 시간 및 언어 > 언어 및 지역 에서 "한국어"가
   설치되어 있어야 하며, 언어 옵션에서 "광학 문자 인식" 기능이 켜져 있어야 합니다.
   (한국어 Windows에는 보통 기본적으로 설치되어 있습니다. 프로그램 실행 시 자동으로
   확인해서, 없으면 안내 메시지를 보여줍니다.)

## 실행 방법

**`실행.bat` 파일을 더블클릭하면 됩니다.**

(명령 프롬프트를 직접 열 필요 없이, 프로젝트 폴더에 있는 `실행.bat` 파일을
더블클릭하면 자동으로 프로그램이 실행됩니다. 프로그램이 종료되면 안내 메시지가
표시되고, 창은 아무 키나 누르기 전까지 닫히지 않습니다.)

직접 명령 프롬프트에서 실행하려면 아래처럼 입력해도 됩니다.

```
python main.py
```

1. **① 게임 창 선택**: 목록에서 홀덤 게임 창을 더블클릭해서 선택합니다.
2. **② 저장 파일 선택**: 결과를 저장할 xlsx 파일 위치를 지정합니다. 이미 있는 파일을
   선택하면 이어서 누적 저장됩니다.
3. **▶ 기록 시작**을 누르면 자동 기록이 시작되고, 화면 아래에 실시간으로 위 형식대로
   행동이 표시됩니다. 다시 누르면 정지합니다. 영역을 따로 지정하지 않아도 창 전체에서
   행동 텍스트만 알아서 걸러내므로 보통은 ①②만으로 충분합니다.
4. **(선택) 특정 영역만 캡처**: 게임 테이블 부분만 좁혀서 캡처하고 싶다면 이 버튼으로
   화면을 드래그해서 영역을 지정할 수 있습니다. 지정하지 않아도 정상 동작합니다.
5. 게임 프로그램이 "New Game" 같은 문구를 보여주지 않아 게임 구분이 자동으로 되지
   않는 경우, **"다음 게임으로 넘기기"** 버튼을 눌러 수동으로 게임 번호를 올리고
   스트리트를 프리플랍으로 되돌릴 수 있습니다.

## 엑셀 파일 형식

| 시간 | 게임 번호 | 스트리트 | 포지션 | 행동 | 금액 | 내 행동 | 원문(OCR) |
|---|---|---|---|---|---|---|---|
| 2026-08-18 21:03:11 | 1 | 프리플랍 | HJ | Raise | 1500 | | Raise 1500 |
| 2026-08-18 21:03:15 | 1 | 프리플랍 | BB | Call | | 예 | Call |

- 내 자리의 행동은 "내 행동" 열이 "예"로 표시되고, 엑셀에서도 초록색 글씨로
  강조됩니다.
- **원문(OCR)** 열에는 인식된 문장이 그대로 남기 때문에, 포지션 추정이나 금액 인식이
  틀리더라도 나중에 원문을 보며 정확히 복기할 수 있습니다.
- 예전 버전 형식으로 만든 xlsx 파일을 이어서 사용하면, 기존 데이터는 아래에 그대로
  남겨두고 새 헤더 행을 추가해서 새 형식으로 이어서 기록합니다.

## 알아두면 좋은 점 / 한계

- **포지션은 실제 딜러 버튼을 화면에서 읽은 것이 아니라, "6명이 계속 앉아 있고 버튼이
  매 핸드 한 자리씩 이동한다"는 가정으로 계산한 값입니다.** 실제로 인원이 바뀌거나
  누군가 자리를 옮기면 계산된 포지션이 실제와 달라질 수 있습니다. 원문(OCR) 열은
  항상 정확하게 남으므로 이런 경우에도 무엇이 있었는지는 확인할 수 있습니다.
- 좌석의 화면상 시계 방향을 판단하는 기준(`src/seat_mapper.py`의
  `SEAT_ORDER_CLOCKWISE`)이 실제 게임과 반대로 나올 수 있습니다. 포지션 순서가
  거꾸로 도는 것 같으면 이 값을 `False`로 바꿔보세요.
- "[N게임 결과]" 줄은 화면에 승리/획득 관련 문구가 보일 때만 best-effort로
  표시됩니다. 항상 나오지 않을 수 있습니다.
- 이 프로그램은 화면에 보이는 텍스트를 OCR로 읽는 방식이라, 게임 화면에 행동이
  글자로 표시되어야 인식할 수 있습니다. (애니메이션/아이콘으로만 표시되는 행동은
  인식하지 못할 수 있습니다.)
- 창이 다른 창에 완전히 가려지면 캡처가 안 될 수 있습니다. 게임 창을 화면에 보이는
  상태로 두고 사용하세요. (최소화는 안 됩니다.)
- 현재 저장 방식은 엑셀(.xlsx) 파일입니다. 구글시트 자동 업로드는 이번 범위에서는
  포함하지 않았습니다 (필요하면 `gspread` 라이브러리로 확장 가능).
- 음성으로 읽어주는 기능(TTS)과 카드 인식은 이번 작업 범위에서 제외했습니다.

## 폴더 구조

```
실행.bat                더블클릭으로 프로그램을 실행하는 배치 파일
main.py                 실행 진입점 (GUI, 색상 태그 적용)
src/
  window_capture.py     창 목록 조회 및 캡처
  region_select.py      (선택 사항) 특정 영역 지정 UI
  ocr_engine.py          Windows OCR 래퍼
  text_diff.py            새로 등장한 텍스트만 골라내는 로직 (위치까지 고려)
  action_parser.py       텍스트에서 행동/스트리트/새 게임/결과 판별
  player_tracker.py      닉네임(좌석) 위치를 추적하는 레지스트리
  seat_mapper.py          좌석 <-> 포지션(UTG/HJ/CO/BTN/SB/BB) 매핑, 내 자리 판별
  xlsx_writer.py          엑셀 파일 누적 저장 (내 행동 강조색 포함, 예전 형식 자동 이관)
  recorder.py             캡처~필터링~포지션 매칭~저장을 반복하는 백그라운드 스레드
  config.py               설정 저장/불러오기 (config.json)
```
