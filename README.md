# 홀덤 게임 텍스트 기록 프로그램

시각장애인 사용자가 온라인 홀덤(ClubWPT GOLD 등 8인 테이블 기준)을 복기하며
공부할 수 있도록, 지정한 게임 창에서 **플레이어들의 행동(Fold/Call/Raise/Bet/
Check/All-in)만** 포지션(딜러/딜러+1/딜러+2 ...)과 스트리트별로 정리해서
텍스트로 기록하고, 엑셀(.xlsx) 파일에 계속 누적 저장하는 프로그램입니다.
**내 자리(화면 하단 중앙)의 행동만 색으로 구분**해서 한눈에 알아볼 수 있습니다.

## 기록 형식

```
[1게임 시작]

[프리플랍]
딜러+1 ] Fold
딜러+2 ] Raise 1500
딜러+3 ] Call

[플랍] 보드: 3장
딜러+3 ] Check
딜러+1 ] Bet 2000

[게임결과] PokerProUS 승 (+15.8)

[2게임 시작]
...
```

- 내 자리의 행동만 화면에서 초록색으로 표시됩니다 (엑셀에도 초록색 글씨로 표시).
- 텍스트 형태(`포지션 ] 행동 [금액]`)는 나와 다른 사람이 완전히 동일하며, "나"라는
  글자는 쓰지 않습니다 — 오직 색으로만 구분합니다.
- 보드 카드는 랭크/수트 값이 아니라 **장수만** 기록합니다 (`table_layout.json`
  설명 참고).

## 동작 원리

전체 화면을 OCR로 훑지 않습니다. `table_layout.json`에 정의된 좌석/보드/결과
패널의 **고정 좌표만** 잘라서 필요한 부분만 인식합니다.

1. 사용자가 화면에 떠 있는 창 목록 중에서 게임 창을 직접 선택합니다.
2. (선택) 게임 테이블 부분만 좁혀서 캡처하고 싶으면 "특정 영역만 캡처"로 영역을
   지정합니다. 유튜브 영상 등 게임 화면이 다른 UI에 둘러싸여 있을 때 유용합니다.
3. 기록이 시작되면, 좌석별 행동 텍스트 영역만 Windows 내장 OCR로 읽습니다. 처리
   비용을 줄이기 위해 매 프레임 모든 좌석을 똑같이 보지 않고, "지금 턴일 것"으로
   예측한 좌석은 항상 확인하고 나머지는 픽셀 변화가 감지된 좌석만 확인합니다
   (`src/recorder.py`의 `_seats_to_watch`).
4. **딜러 버튼 위치는 OCR로 읽지 않습니다.** "D" 한 글자는 Windows OCR이 원리적으로
   인식하지 못하는 것을 실측으로 확인해서, opencv로 흰 원 모양을 직접 검출합니다
   (`src/dealer_position.py`). 새 핸드가 시작되면 "이전 딜러의 다음 자리"부터
   우선 확인하고, 못 찾을 때만 전체 좌석을 훑습니다.
5. **보드 카드 장수도 OCR로 읽지 않습니다.** 카드 랭크(K, Q 등) 폰트를 Windows
   OCR이 읽지 못하는 것을 실측으로 확인해서, 보드 영역의 밝은 픽셀 폭으로 카드가
   몇 장 나왔는지(0/3/4/5)만 판별합니다 (`src/board_reader.py`). 이 장수로
   프리플랍/플랍/턴/리버를 구분하고, 0장으로 돌아오면 새 핸드가 시작된 것으로
   봅니다.
6. 화면 우측 "내기록"류 결과 패널에서 "닉네임 : +금액" 형태의 줄을 찾아 승리를
   기록합니다 (해당 탭이 선택되어 있어야 보입니다).
7. 같은 행동이 OCR 잡음으로 여러 프레임에 걸쳐 살짝 다르게 잡혀도, "이 좌석이 이
   스트리트에 마지막으로 기록한 (행동, 금액)"과 같으면 다시 기록하지 않습니다
   (`src/recorder.py`의 의미 기준 중복 방지).

## 설치

1. Python 3.11 이상 (Windows) 필요
2. 아래 명령으로 패키지를 설치합니다.

   ```
   pip install -r requirements.txt
   ```

3. **한국어 OCR 언어 팩 확인**: 설정 > 시간 및 언어 > 언어 및 지역 에서 "한국어"가
   설치되어 있어야 하며, 언어 옵션에서 "광학 문자 인식" 기능이 켜져 있어야 합니다.
   (한국어 Windows에는 보통 기본적으로 설치되어 있습니다. 프로그램 실행 시 자동으로
   확인해서, 없으면 안내 메시지를 보여줍니다.)

## 실행 방법

**`실행.bat` 파일을 더블클릭하면 됩니다.**

(명령 프롬프트를 직접 열 필요 없이, 프로젝트 폴더에 있는 `실행.bat` 파일을
더블클릭하면 자동으로 프로그램이 실행됩니다.)

직접 명령 프롬프트에서 실행하려면 아래처럼 입력해도 됩니다.

```
python main.py
```

프로그램은 중복 실행을 막습니다 — 이미 켜져 있는 상태에서 다시 실행하면 안내
메시지만 뜨고 새 창은 열리지 않습니다(같은 저장 파일에 여러 프로세스가 동시에
쓰려다 충돌하는 것을 막기 위함입니다).

1. **① 게임 창 선택**: 목록에서 홀덤 게임 창을 더블클릭해서 선택합니다.
2. **② 저장 파일 선택**: 결과를 저장할 xlsx 파일 위치를 지정합니다. 이미 있는 파일을
   선택하면 이어서 누적 저장됩니다.
3. **(선택) 특정 영역만 캡처**: 게임 테이블 부분만 좁혀서 캡처하고 싶다면 이 버튼으로
   화면을 드래그해서 영역을 지정할 수 있습니다. `table_layout.json`의 좌표는 이
   영역(또는 창 전체)의 상대 비율로 적용됩니다.
4. **▶ 기록 시작**을 누르면 자동 기록이 시작되고, 화면 아래에 실시간으로 위 형식대로
   행동이 표시됩니다. 다시 누르면 정지합니다.
5. 보드 장수가 0장으로 돌아오는 시점을 새 핸드 시작으로 자동 인식합니다. 잘 안 되는
   경우 **"다음 게임으로 넘기기"** 버튼으로 수동으로 넘길 수 있습니다.

## 좌표가 화면에 안 맞을 때 (`table_layout.json`)

이 프로그램은 게임 UI의 **고정 좌표**를 미리 재서 씁니다. 게임/영상 창의 크기나
비율이 바뀌면(특히 다른 유튜브 영상으로 테스트할 때) 좌표가 어긋날 수 있습니다.
`table_layout.json`을 실제 화면에 맞춰 다시 재야 합니다 — `base_resolution`
(기준 캡처 크기)과 `seats`/`board_region`/`hole_cards_region`/
`result_panel_region`을 그 크기 기준 좌표로 채웁니다. 같은 영상이라도 카드
렌더링 크기가 다르면 `src/board_reader.py`의 `CARD_UNIT_WIDTH`도 같이 조정해야
할 수 있습니다.

## 엑셀 파일 형식

| 시간 | 게임 번호 | 스트리트 | 포지션 | 행동 | 금액 | 내 행동 | 원문(OCR) |
|---|---|---|---|---|---|---|---|
| 2026-08-19 21:03:11 | 1 | 프리플랍 | 딜러+2 | Raise | 1500 | | RAISE 1500 |
| 2026-08-19 21:03:15 | 1 | 프리플랍 | 딜러+4 | Call | | 예 | CALL |

- 내 자리의 행동은 "내 행동" 열이 "예"로 표시되고, 엑셀에서도 초록색 글씨로
  강조됩니다.
- **원문(OCR)** 열에는 인식된 문장이 그대로 남기 때문에, 포지션 추정이나 금액 인식이
  틀리더라도 나중에 원문을 보며 정확히 복기할 수 있습니다.
- 승리 결과 행은 "포지션" 열에 닉네임이, "행동" 열에 `Win`이 들어갑니다.

## 알아두면 좋은 점 / 한계

- 딜러 버튼과 보드 카드 장수는 OCR이 아니라 픽셀/이미지 처리로 판별하므로, 게임
  UI 배색이나 카드 크기가 크게 다른 새 영상/게임으로 바꾸면 임계값을 다시 맞춰야
  할 수 있습니다.
- 카드 랭크/수트 값(예: Ks, 6c)은 인식하지 않습니다 — Windows OCR이 카드 폰트를
  읽지 못하는 것을 실측으로 확인했습니다. 보드는 장수만, 홀카드는 아직 미지원입니다.
- 화면에 아주 짧게 떴다 사라지는 행동은 캡처 주기보다 짧으면 원리적으로 놓칠 수
  있습니다.
- 결과 패널 인식은 "내기록" 같은 탭이 선택되어 있어야 동작합니다. "채팅" 탭 등
  다른 탭이 선택돼 있으면 그동안은 승패가 안 잡힙니다.
- 창이 다른 창에 완전히 가려지거나 최소화되면 캡처가 안 될 수 있습니다.
- 현재 저장 방식은 엑셀(.xlsx) 파일입니다. 구글시트 자동 업로드는 이번 범위에서는
  포함하지 않았습니다.
- 음성으로 읽어주는 기능(TTS)은 이번 작업 범위에서 제외했습니다.

## 폴더 구조

```
실행.bat                더블클릭으로 프로그램을 실행하는 배치 파일
main.py                 실행 진입점 (GUI, 색상 태그 적용, 중복 실행 방지)
table_layout.json       좌석/보드/홀카드/결과패널 고정 좌표 설정
src/
  window_capture.py     창 목록 조회 및 캡처
  region_select.py      (선택 사항) 특정 영역 지정 UI
  table_layout.py       table_layout.json 로더 + 좌표 스케일링
  ocr_engine.py          Windows OCR 래퍼
  text_diff.py            새로 등장한 텍스트만 골라내는 로직 (위치까지 고려)
  action_parser.py       텍스트에서 행동/금액/결과 줄 판별
  board_reader.py        보드 카드 장수를 픽셀 밝기로 판별 (OCR 아님)
  dealer_position.py     딜러 버튼을 opencv 원 검출로 판별 (OCR 아님) + 포지션 계산
  xlsx_writer.py          엑셀 파일 누적 저장 (내 행동 강조색 포함, 예전 형식 자동 이관)
  recorder.py             캡처~좌석별 OCR~행동 판별~포지션 계산~저장을 반복하는 백그라운드 스레드
  config.py               설정 저장/불러오기 (config.json)
```
